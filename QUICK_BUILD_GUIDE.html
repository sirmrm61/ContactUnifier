Contact Unifier

Build APK → Test on Emulator → Share with Family

1 Create GitHub Repo (2 min)

Go to https://github.com/new

  • Name: ContactUnifier
  • Visibility: Private
  • Create → Copy URL

2 Push Your Code (1 min)

Run in PowerShell:

cd D:\project\cc_project\contactMerge\ContactUnifier

git init
git config user.email "sir.mrm@gmail.com"
git config user.name "Developer"
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ContactUnifier.git
git push -u origin main

Replace YOUR_USERNAME with your GitHub username

3 Build in Cloud (5-7 min)

Go to your GitHub repo → Actions tab

Watch "Build Contact Unifier APK":

Start 🟡 Yellow = building
5-7 min ✅ Green = done

4 Download APK (1 min)

When build succeeds:

  • Click the build (green checkmark)
  • Scroll to Artifacts
  • Download contact-unifier-debug.zip
  • Extract to get app-debug.apk

5 Test on Emulator (5 min)

Run in terminal:

adb devices
adb install -r app-debug.apk
adb shell am start -n com.contactunifier/.MainActivity

Then test:

  • ✅ Splash screen animates
  • ✅ Grants permissions
  • ✅ Shows duplicate contacts (create test ones first)
  • ✅ Merge flow works
  • ✅ Language switching (EN ↔ FA)
💡 TL;DR: Push to GitHub → GitHub builds automatically → Download APK → Test on emulator. No local Android SDK setup needed.
